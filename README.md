# Lomari CRM: downloaden

Het klantsysteem van het Lomari-team. Je hebt een **uitnodiging per e-mail** nodig om in te loggen; zonder uitnodiging werkt de app niet.

| Computer | Download |
| --- | --- |
| **Mac** (Intel en Apple-chip) | [Lomari-CRM-Mac.dmg](https://github.com/Ruben-Blummel/lomari-crm-downloads/releases/latest/download/Lomari-CRM-Mac.dmg) |
| **Windows** | [Lomari-CRM-Windows.exe](https://github.com/Ruben-Blummel/lomari-crm-downloads/releases/latest/download/Lomari-CRM-Windows.exe) |

Deze links geven altijd de nieuwste versie. Alle versies staan onder [Releases](https://github.com/Ruben-Blummel/lomari-crm-downloads/releases).

## Installeren op een Mac

1. Open **Lomari-CRM-Mac.dmg** en sleep **Lomari CRM** naar de map **Programma's**.
2. Open Lomari CRM vanuit Programma's. macOS meldt dat Apple de app niet kan controleren: klik op **Gereed**.
3. Open **Systeeminstellingen → Privacy en beveiliging**, scrol naar beneden en klik bij Lomari CRM op **Open toch**. Bevestig met je wachtwoord of Touch ID en klik nog een keer op **Open toch**.

Daarna opent de app voortaan gewoon.

## Installeren op Windows

1. Open **Lomari-CRM-Windows.exe**.
2. Zegt Windows *"Windows heeft uw pc beveiligd"*, klik dan op **Meer informatie → Toch uitvoeren**.
3. Klik op **Installeren**. Er komt een snelkoppeling op je bureaublad.

## Eerste keer inloggen

1. Klik op het inlogscherm op **"Uitnodiging ontvangen? Vul je code in"**.
2. Vul je e-mailadres en de **code van 6 cijfers** uit de uitnodigingsmail in (kijk ook in je spam).
3. Kies een wachtwoord van minimaal 10 tekens.
4. Scan de QR-code met **Google Authenticator** of **Microsoft Authenticator** en vul de code uit die app in.

Code verlopen of vragen? Neem contact op met de beheerder.
